# School TV Control System

A system to allow the school administration to display notices on multiple TVs across the campus from one central computer.

## Current Progress

- ✅ Git repository initialized
- ✅ Flask server created
- ✅ Server health endpoint (/)
- ✅ GET /get_notice reads the latest notice
- ✅ POST /update_notice updates the latest notice
- ✅ Python VP client sends notices to the server successfully
